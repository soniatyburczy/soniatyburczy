# Hi, I'm Sonia!

I'm a math student at Baruch College working across data science, machine learning, and model evaluation. I'm especially interested in **what the metrics miss** — hidden subgroups, undocumented data artifacts, and the gap between a better score and a system that actually works.

### Selected work

* **Structural Predictors of Chronic Absenteeism in NYC Public Schools**  
  Compared statistical and tree-based models on NYC DOE data to study structural drivers of absenteeism and the impact of an administrative data shift.  
  → https://github.com/soniatyburczy/absenteeism-structural-predictors

* **Looking Beyond Accuracy: Subgroup Recall in Adult Income Classification**  
  Compared logistic regression and a neural network, showing how nearly identical F1 scores can hide meaningful subgroup recall differences.  
  → https://github.com/soniatyburczy/adult-income-subgroup-analysis

* **Fine-Tuning LLaMA-2-7B-Chat with QLoRA**  
  Fine-tuned LLaMA-2-7B-Chat with QLoRA for structured cover-letter generation, improving grounding, semantic similarity, and repetition.
  → https://github.com/soniatyburczy/llama2-qlora-finetune
